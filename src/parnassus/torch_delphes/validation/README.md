# Parnassus.TorchDelphes

## Validation pipeline

TorchDelphes Validation Test Suite.

Processes HepMC files through TorchDelphes and validates output against
C++ Delphes benchmarks. Generates comparison histograms for all output
branches to verify implementation correctness.

TorchDelphes currently emulates **Delphes 3.5.0**

### 1. Generate HepMC input

Via Parnassus.Pythia:
```
python HZZ4l.py
```

Or, via C++ (must have Pythia8 and HepMC3 installed):
```
export LD_LIBRARY_PATH=<HepMC3_INSTALL_PATH>/hepmc3-install/lib64:$LD_LIBRARY_PATH
g++ -O2 -std=c++17 pythia_cards/HZZ4l.cc -o bin/HZZ4l $(bin/pythia8-config --cxxflags --libs) -I<HepMC3_INSTALL_PATH>/hepmc3-install/include -L<HepMC3_INSTALL_PATH>/hepmc3-install/lib64 -lHepMC3
./bin/HZZ4l
```

### 2. Generate ROOT benchmark for comparison (must have Delphes and ROOT installed)
```
<Delphes_INSTALL_PATH>/DelphesHepMC3 delphes_cards/delphes_card_CMS_eflow.tcl data/HZZ4l/CMS/HZZ4l_1k_eflow.root data/HZZ4l/events.hepmc
```

### 3. Validate TorchDelphes against benchmark generated by C++ Delphes
```
python validate_torch_delphes.py --det=CMS --process=HZZ4l
```
